# Архив старого miningshop.ru

Всё, что удалось восстановить от интернет-магазина miningshop.ru, работавшего на Битриксе (шаблон Aspro Next)
до января 2026 года, плюс история его трафика из Яндекс.Метрики. Репозиторий — рабочий материал для
наполнения нового сайта: тексты, характеристики, фото, структура разделов, данные о том, что приносило трафик.

**Репозиторий приватный намеренно.** Если выложить эти тексты в открытый доступ (например, через GitHub Pages),
поисковики проиндексируют их раньше, чем они появятся на новом miningshop.ru, и дублем окажется уже
основной сайт.

## Что внутри

| Папка / файл | Что это |
|---|---|
| `index.html` | Оглавление: все товары по разделам, статьи, разделы каталога, прочие страницы — со ссылками на копии и тексты |
| `mirror/` | Копии старых страниц в исходном виде, со всеми картинками и стилями. Ссылки переписаны на локальные, счётчики Метрики и чаты вырезаны |
| `content/` | Текст каждой страницы в Markdown с метаданными: `product/`, `article/`, `category/`, `blog_section/`, `page/` |
| `data/products.csv` | Таблица товаров для Excel: название, раздел, цена, наличие, характеристики, адреса фото |
| `data/*.json` | То же в JSON: товары, статьи, разделы, страницы |
| `analytics/REPORT.md` | **Отчёт**: трафик 2017–2026, на чём держался сайт, что восстановить, что убрать, спрос на ИИ-направление |
| `analytics/metrika_raw/` | Выгрузки Метрики: посещаемость по месяцам, источники по годам, поисковые фразы, страницы входа |
| `analytics/wordstat_*.txt` | Спрос в Вордстате по GPU/ИИ, фермам и комплектующим |
| `_work/` | Скрипты, которыми всё собрано: можно перезапустить |

## Как посмотреть старый сайт

Страницы ссылаются друг на друга относительными путями, поэтому проще всего поднять локальный сервер
из корня репозитория:

```bash
python -m http.server 8000
```

Затем открыть `http://localhost:8000/` — это оглавление, а `http://localhost:8000/mirror/` — главная старого сайта.

## Откуда данные

Страницы и файлы — из веб-архива (web.archive.org): для каждого адреса взят самый свежий снимок со статусом 200,
в исходном виде (режим `id_`, без панели архива). Технические дубли (utm-метки, сброс кеша Битрикса, bxrand)
отброшены, служебные разделы (админка, личный кабинет, оформление заказа) не выкачивались.

Что попало в архив, а что нет, решал сам веб-архив: часть карточек сохранилась только в старых снимках 2019–2021 годов,
часть картинок не сохранилась вовсе. Такие ссылки в копиях ведут на веб-архив.

Метрика — счётчик 45472341, отчёты сняты через интерфейс 23.09.2026.
