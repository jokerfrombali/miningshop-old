## Описание

Видеокарта ASUS AMD Radeon RX 570 EXPEDITION [EX-RX570-4G] отличается высоким уровнем качества, что неудивительно: перед вами продукция легендарного производителя ASUS. Модель наилучшим образом подходит для монтажа в игровой компьютер, который используется для игр любых жанров. «Движущей силой» модели является популярный графический процессор AMD Radeon RX 570, штатная частота которого равна 1244 МГц. Для установки видеокарты используется слот PCI-E. Мультипроцессорная конфигурация не поддерживается, поэтому видеоадаптер станет отличным выбором для пользователей, которым неинтересна возможность использования нескольких видеокарт.

Видеокарта ASUS AMD Radeon RX 570 EXPEDITION [EX-RX570-4G] имеет 3 видеоинтерфейса: DVI-D, DisplayPort и HDMI. Вы сможете подключить 3 монитора одновременно. При монтаже видеокарты нужно предусмотреть возможность обеспечения дополнительного питания, с использованием разъема 8-pin. Максимальное энергопотребление видеокарты, составляющее 150 Вт, обуславливает необходимость наличия источника питания с мощностью не ниже 450 Вт. В комплект входит диск с ПО.
