# Устранение различных проблем с Antminer

![Устранение различных проблем с Antminer Устранение различных проблем с Antminer](/upload/iblock/811/8111eedb93623ac8617891acc1f41607.jpg)

Одной из самых распространенных проблем с устройствами для добычи криптовалют является излишний издаваемый шум, который не понравится никому. Это связано с мощными кулерами, которые охлаждают устройство для сохранения их рабочего состояния в течение долгих лет.

Некоторые умельцы рекомендуют снизить их мощность примерно на треть, ведь как показывает практика, излишний поток воздуха никаким образом не будет способствовать более стабильной работе системы. Ведь устройство, в котором кулер работает даже на 2/3, стабильно держит рабочую температуру, которая не имеет свойства неожиданно подниматься.


Проблему с шумом вентиляторов давно решили профессиональные добытчики криптовалюты, которые модернизировали свои устройства трубчатой системой охлаждения, а также размещают из в специально предназначенном для этого помещении. Но вот тем майнерам, которые имеют в наличии не более двух устройств, данная проблема доставляет немало неудобств, ведь нахождение в одной комнате с такими машинами – та еще пытка.


Решением данной проблемы станет установка менее мощных вентиляторов. Одной из самых популярных моделей для этой цели стали кулеры AFC1212DE. Они отвечают всем необходимым требованиям для АСИК устройств, издавая при этом почти в половину меньше шума. При одинаковой скорости вращения эти вентиляторы издают намного меньше шума, что вызвано уникальным двигателем, вращающим лопасти, а также применением новой технологии использования подшипников.
